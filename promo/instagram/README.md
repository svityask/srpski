## Рилс №1 «Ты уже знаешь сербский»

`reel-1-uzhe-znaesh.mp4`: 1080×1920, 18,7 с, 30 кадров/с, без звука — музыку добавить в Instagram.
Обложка — `reel-1-cover.jpg` (в сетке профиля Instagram покажет середину 3:4, текст туда помещается).

**Раскадровка:**

| Время | Что на экране |
|---|---|
| 0–2,2 с | Крючок: «Ты уже знаешь **сербский** — просто ещё не знаешь об этом», выезжает табличка Ćao! |
| 2,2–9,2 с | 8 табличек подряд, ~0,9 с на каждую: Voda, Pivo, Hleb, Brat, Sestra, Taksi, Ključ, Policija → под каждой ✓ русское слово. Сверху точки-счётчик 1…8 |
| 9,2–13,7 с | «Но осторожно — ложные друзья»: Sutra (~~утро?~~ → завтра), Pravo (~~право?~~ → прямо), Stolica (~~столица?~~ → стул). Табличка вздрагивает на ошибке |
| 13,7–18,7 с | «50 таких слов в бесплатном приложении Srpski», снизу выезжает телефон с курсом, кнопка «Ссылка в профиле» пульсирует |

**Музыка:** Goran Bregović — «Kalashnikov», фрагмент с духовыми с самого начала. Темп быстрый — смена табличек ложится примерно на доли.

**Подпись:**

```
Проверь себя: сколько слов понял без перевода? 👀

voda, pivo, hleb, brat — сербский звучит как родной. Но sutra — это не «утро» 😅

Сохрани, чтобы не попасть впросак в Белграде 📌
Больше слов — в бесплатном приложении, ссылка в профиле.

#сербскийязык #сербия #белград #русскиевсербии #релокация #изучениеязыков
```

**Как перерисовать:** `node reel-frames.js <папка с reel-1-source.html и app-course.png> <папка кадров>`, затем
`ffmpeg -framerate 30 -i кадры/%04d.jpg -c:v libx264 -pix_fmt yuv420p -crf 18 reel.mp4`.
Файл `reel-1-source.html` нужно переименовать в `reel.html`.

## Рилс №3 «Сербский сленг» — с мультперсонажем

`reel-3-sleng.mp4`: 1080×1920, 37,6 с, **с голосом серьёзного диктора** (синтез RHVoice, голос Aleksandr HQ, чуть ниже и быстрее обычного; рот персонажа движется по громкости голоса). Отдельная дорожка голоса — `reel-3-voice.mp3`. Обложка — `reel-3-cover.jpg`, исходник — `reel-3-source.html`.
Ведущий — векторный мультперсонаж по фото автора (тёмные волосы с пробором, карие глаза, щетина, чёрная футболка): моргает, «говорит», меняет мимику.

| Время | Голос диктора |
|---|---|
| 0–5,5 с | «Сербский сленг. Четыре слова, без которых вы — не свой.» |
| 5,5–12,8 с | «Слово первое. Брате. Братан. Брате, где си? — Братан, ты где?» |
| 12,8–18,4 с | «Слово второе. Айде бре! Ну давай уже. Айде бре, идемо!» |
| 18,4–23,9 с | «Слово третье. Полако. Спокойно, не спеши. Успеем.» |
| 23,9–28,6 с | «Слово четвёртое. Какав смор. Какая скукота.» |
| 28,6–37,6 с | «Капираш? Догоняешь? Больше живого сербского — в бесплатном приложении Српски. Ссылка в профиле.» |

Перевод на карточке появляется в момент, когда диктор его произносит. Чтобы переозвучить своим голосом: записать те же 6 фраз и заменить дорожку — `ffmpeg -i reel-3-sleng.mp4 -i мой-голос.m4a -map 0:v -map 1:a -c:v copy -shortest out.mp4`.

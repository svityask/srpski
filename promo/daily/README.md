# Ежедневные публикации @srpski_coach

Каждый день, время Белграда — Instagram и Telegram (t.me/srpski_coach), со ссылками друг на друга:

| Время | Что | Instagram | Telegram |
|---|---|---|---|
| 10:00 | Слово дня | карточка 4:5 | та же карточка + ссылка на пост в Instagram |
| 15:00 | Урок из приложения | карусель 4–5 слайдов | все слайды одной картинкой-сеткой + ссылка на карусель |
| 18:00 | Проверь себя | карусель «вопрос → ответ» | сетка + опрос-викторина |

- `plan.json` — очередь: подписи, картинки, статус (`pending` / `published` / `skipped`), ссылки на опубликованное.
- `<дата>/` — картинки на каждый день.
- Новые дни: `node promo/tools/daily.js --days 14` (продолжит с последнего дня, слова и уроки не повторяются).
- Публикация: `node promo/tools/slot.js next` → выложить → `node promo/tools/slot.js done <дата> <время> <ссылка Instagram> <id сообщения Telegram>`.

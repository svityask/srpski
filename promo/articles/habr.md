# Переехал в Сербию и сделал бесплатное приложение для сербского: PWA без сервера, озвучка, падежи и интервальные повторения

![Главный экран и раздел «Учиться»](img/home.jpg)

Когда переезжаешь в Сербию, кажется, что язык выучится сам: славянский, половина слов знакомая, «hleb», «voda», «brat». Через неделю выясняется, что «sutra» — это не «утро», а «завтра», «pravo» — «прямо», а «Zovem mamu» — «звоню маме», хотя падеж винительный. Вывески на латинице, документы на кириллице, а в МУПе (миграционной полиции) никто не говорит по-русски.

Я искал приложение, которое учит сербскому именно русскоязычных, с бытовыми фразами «для жизни», а не «мальчик ест яблоко». Не нашёл подходящего и сделал своё: **[Srpski](https://zdravo.srpski.workers.dev/)**. Бесплатно, без регистрации, работает офлайн, ставится на iPhone как приложение.

Ниже — что внутри и как это сделано технически: без бэкенда, без фреймворков и без сборки.

## Что умеет

- **Курс** из 10 юнитов и 31 урока, 318 слов и фраз: приветствия, кафе, рынок, транспорт, квартира, документы, врач, разговорный сленг. В конце юнита — тест.
- **Упражнения**: выбор перевода, «на слух», ввод с клавиатуры, сборка фразы из слов, пары, диктант.
- **Интервальные повторения**: слово возвращается через 1, 2, 4, 8, 16, 32 дня; ошибка — в начало.
- **Победи падежи**: 7 падежей на 40 фразах из жизни («Idem kod lekara», «Živim u Beogradu») и ловушки для русских.
- **Диалоги по ролям**: кафе, рынок, такси, аптека, МУП. Можно включить режим «Я — посетитель»: ваши реплики скрыты, нужно сказать их вслух.
- **Чтение**: короткие истории, нажатие на предложение — озвучка и перевод.
- **«Говори! Тема на барабане»**: колесо выбирает тему, таймер на минуту речи, запись своего голоса.
- **Дорожная карта** A1 → A2, урок дня, сад, который растёт от опыта, тёмная тема.

## Стек: ничего лишнего

Это PWA на чистом JavaScript: `index.html`, один CSS и несколько JS-файлов с данными. Около 260 КБ вместе с контентом. Никакого React, никакой сборки, никакого сервера. Состояние — в `localStorage`, офлайн — через Service Worker, хостинг — статика на Cloudflare Workers (бесплатный тариф).

Почему так:

1. **Скорость**. Приложение открывается мгновенно даже на плохом мобильном интернете.
2. **Ноль расходов**. Нет сервера — нечему падать и не за что платить.
3. **Приватность**. Прогресс не уходит никуда с телефона. Для переноса на другое устройство — код-копия (base64 от JSON состояния), который можно сохранить в Заметки.

## Две азбуки: латиница → кириллица

Сербский пишется и латиницей, и кириллицей, причём соответствие однозначное: одна буква — один звук. Поэтому весь контент хранится на латинице, а кириллица строится на лету. Единственная тонкость — диграфы `lj`, `nj`, `dž`, которые превращаются в одну букву (`љ`, `њ`, `џ`):

```js
const L2C_DI = { lj: 'љ', nj: 'њ', 'dž': 'џ' };
function toCyr(s) {
  let out = '';
  for (let i = 0; i < s.length; i++) {
    const di = L2C_DI[s.substr(i, 2).toLowerCase()];
    if (di) { out += isUp(s[i]) ? di.toUpperCase() : di; i++; continue; }
    const c = L2C[s[i].toLowerCase()];
    out += c ? (isUp(s[i]) ? c.toUpperCase() : c) : s[i];
  }
  return out;
}
```

Пользователь выбирает основную азбуку, вторая показывается мелко — как на эмалированных табличках улиц в Белграде. Отсюда и дизайн карточек слов.

## Проверка ответа «по-человечески»

Сербская раскладка есть не у всех, а набирать `č ć š ž đ` на телефоне долго. Поэтому ответ сравнивается в два прохода: сначала точно, потом «по скелету» — без диакритики, а ввод русскими буквами переводится в латиницу:

```js
const bare = (s) => norm(s)
  .replace(/đ/g, 'dž').replace(/[čć]/g, 'c').replace(/š/g, 's').replace(/ž/g, 'z')
  .replace(/dj/g, 'dz').replace(/lj/g, 'l').replace(/nj/g, 'n');
```

«здраво», «zdravo» и «Zdravo!» засчитываются одинаково, а при неточном написании приложение показывает правильный вариант.

## Подсказка произношения русскими буквами

Для новичка `[љ]` и `[ћ]` ничего не говорят, поэтому под каждым словом — транскрипция кириллицей «по-русски»: `ljubav` → «любав», `njegov` → «негов», `kuća` → «куча». Правила простые, но с подвохами: `j` перед гласной даёт «я/е/ю», после согласной нужен мягкий знак, а `e` после гласной — «э».

Самый смешной баг был в этой функции: `VOW.includes('')` возвращает `true`, и в конце слова «j» тихо пропадала. Classic JavaScript.

## «Вы уже знаете эти слова»

Хотелось показать новичку, что он знает сербский лучше, чем думает. Вместо ручного списка приложение само находит слова курса, которые звучат как русские: сравнивает транскрипцию с переводом по расстоянию Левенштейна. Расстояние 0 — «совпадают полностью» (voda, brat, taksi), 1 — «отличаются одной буквой» (riba — рыба). Ложных друзей отсекает пометка в данных, иначе «sutra» попало бы в «знакомые».

## Варианты ответа без двусмысленности

Классическая проблема тестов: если в вариантах есть «Привет» и «Привет / Пока», правильными оказываются оба. Варианты подбираются так, чтобы «смыслы» (переводы, разбитые по `/`) не пересекались, сначала из того же урока, потом из юнита, потом из всего курса. Так отвлекающие варианты похожи по теме, но однозначны.

## Падежи на живых фразах

Для тренажёра падежей я вручную описал формы 24 существительных во всех семи падежах и 40 фраз с пропуском:

```js
{ id: 'c29', s: 'Svako veče zovem ___.', n: 'mama', c: 'A',
  ru: 'Каждый вечер звоню маме.', why: 'Ловушка: zvati koga? — akuzativ, хотя по-русски «кому»' }
```

Варианты ответа — другие формы того же слова, так что угадать по окончанию «похоже/не похоже» не выйдет. Звательный падеж у неодушевлённых («posle» от «posao») в варианты не попадает — звучит неестественно и сбивает.

## Озвучка: сербского голоса в iOS нет

Озвучка — через `speechSynthesis`. Сюрприз: в iOS нет сербского голоса. Зато есть хорватский, а литературное произношение у них почти одинаковое. Поэтому голос выбирается по цепочке `sr → hr → bs`:

```js
for (const re of [/^sr/i, /^hr/i, /^bs/i]) {
  const v = speechSynthesis.getVoices().find((x) => re.test(x.lang));
  if (v) { tts.voice = v; return; }
}
```

В диалогах у собеседников разная высота голоса, а реплики ставятся в очередь `speechSynthesis` с подсветкой текущей через `onstart`.

## Главная ловушка PWA на iPhone: прогресс может пропасть

Это стоит знать всем, кто делает PWA с `localStorage`:

- во встроенном браузере Instagram данные хранить ненадёжно;
- Safari может удалить данные сайта, если его долго не открывать;
- **хранилище Safari и приложения «на экране Домой» — разные**. Прошёл 10 уроков в браузере, добавил на экран — начинаешь с нуля.

Поэтому приложение само определяет, что открыто не как установленное (`navigator.standalone`, `display-mode: standalone`), и показывает подсказку: в Instagram — «Откройте в Safari», в Safari — «Поделиться → На экран „Домой“». Плюс `navigator.storage.persist()` и экспорт кода прогресса.

## Service Worker и видео

Ещё одна грабля: Service Worker, который кэширует всё подряд, ломает загрузку видео в Safari (Range-запросы). Решение — пропускать мимо кэша запросы с `Range` и `destination` `video/audio`, а кэшировать только ответы со статусом 200.

# Srpski — сербский для русских

Карманное веб-приложение для iPhone: базовые слова и фразы, чтобы освоиться в сербской среде.
Без сервера, без регистрации, работает офлайн после первого открытия.

## Курс

| Юнит | Уроки |
|---|---|
| 1. Первые слова | Приветствия · Да / Нет · Как дела |
| 2. Знакомство | Как тебя зовут · Откуда ты · Возраст и работа |
| 3. Числа и время | Числа 0–10 · Числа 11–1000 · Который час · Дни недели |
| 4. Еда и напитки | В кафе · Продукты · В ресторане · Сербская кухня |
| 5. Семья | Близкие · Родственники · О своей семье |
| 6. В городе | Места · Как пройти · Транспорт |
| 7. Покупки | В магазине · На рынке · Цвета и одежда |
| 8. Путешествия | Вокзал и аэропорт · Жильё · Погода |
| 9. Жизнь в Сербии | Квартира · Документы · Здоровье |
| 10. Разговорный сербский | Словечки · Ложные друзья |

В конце каждого юнита — тест (нужно 80% верных ответов).

## Что умеет

- **Уроки**: карточка нового слова → «что это значит?» → пары, выбор перевода, «на слух», ввод с клавиатуры, сборка фразы из слов. Ошибку урок вернёт в конце ещё раз.
- **Латиница и кириллица**: переключатель в «Ещё», второй алфавит мелко под основным — как на табличках улиц в Белграде. Кириллица строится из латиницы автоматически.
- **Ввод без сербской клавиатуры**: можно без č ć š ž đ и даже русскими буквами («здраво» засчитается как Zdravo).
- **Озвучка** через голос iOS. Сербского голоса в iOS нет, используется хорватский — произношение почти то же. Если звука нет: Настройки → Универсальный доступ → Устный контент → Голоса → Хорватский → скачать.
- **Карточки**: колода по всем 318 фразам или по теме, переворот нажатием, «Знаю» и «Повторить» (или свайп), картинки к 302 фразам, второй круг только по незнакомым.
- **Повтор** по интервалам (1, 2, 4, 8, 16, 32 дня); ошибка возвращает слово в начало.
- **Разговорник**: вкладка «Как по-русски» (слова курса, которые звучат как русские — находятся автоматически), все фразы с поиском и **азбука** с произношением.
- **Главный экран «Сегодня»**: приветствие по-сербски, кольцо цели дня, серия дней, слово дня. Юниты раскрашены, как линии транспорта. Тема: системная, светлая или тёмная.
- **Автосохранение после каждого ответа.** Если закрыть приложение посреди урока, при следующем запуске оно откроется на том же задании. Крестик закрывает урок без вопросов, а на главной появляется «Продолжить с места остановки». Последняя открытая вкладка тоже запоминается.
- Серия дней, XP, звёзды за уроки. Прогресс — в памяти телефона; в «Ещё» есть код для резервной копии.

## Установка на iPhone

1. Включить GitHub Pages: репозиторий → **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
2. Открыть `https://svityask.github.io/srpski/` в **Safari**.
3. «Поделиться» → **«На экран „Домой“»**. Приложение откроется на весь экран и будет работать без интернета.

## Как добавить слова или урок

Весь контент — в [`js/data.js`](js/data.js). Элемент урока: `['сербский латиницей', 'перевод', 'заметка (необязательно)']`.
Варианты через ` / ` засчитываются все. `id` существующих уроков не меняйте — по ним хранится прогресс.
После правок поднимите `VERSION` в [`sw.js`](sw.js), чтобы телефон подтянул новую версию.

## Устройство

Обычные HTML/CSS/JS без сборки и зависимостей: `index.html`, `css/app.css`, `js/data.js` (курс), `js/app.js` (логика), `sw.js` (офлайн), `manifest.webmanifest` и `icons/`.
Локально: `python3 -m http.server` в папке репозитория и открыть `http://localhost:8000`.
